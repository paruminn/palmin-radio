# スマホでパルミンラジオを聴く

## ホーム画面に追加

### Android（Chrome）

1. Chromeで <https://paruminn.github.io/palmin-radio/> を開く
2. 右上の「︙」を押す
3. 「アプリをインストール」または「インストールしてショートカットを作成」を選ぶ
4. 画面の案内に沿って追加する

### iPhone（Safari）

1. Safariで <https://paruminn.github.io/palmin-radio/> を開く
2. 「共有」を押し、「ホーム画面に追加」を選ぶ
3. 「Webアプリとして開く」が表示されたらオンにして「追加」を押す

## 再生と操作

ホーム画面のアイコンから開き、再生ボタンで聴き始めます。再生・一時停止、再生位置、速度、音量を画面下のプレーヤーから操作できます。番組の音声はインターネット経由で読み込みます。

スマホからできるのは公開中の番組を聴く操作です。新しい音声の作成は、PCで起動したCOEIROINKを使います。COEIROINKのAPIはPC内だけで利用し、スマホや外部ネットワークには公開しません。
