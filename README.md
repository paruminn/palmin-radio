# パルミンラジオ

**好きなことから、世界の新しい発見まで。**

パルミンラジオは、パルミンの興味に合わせたニュースを、レティシア・フィーユ・シェロの3人が届ける個人向けニュースラジオです。

## 放送内容
- **約60%：趣味・関心** — AI・生成AI、ゲーム、PC・スマートフォン・ガジェット、ソフトウェア、音楽（特にメロディックデスメタル）、ロボット・電子工作・3D技術
- **約20%：科学・技術** — 宇宙、研究成果、セキュリティ、医療技術を含む科学技術の重要な進展
- **約20%：社会・世界** — 国内外の重要な出来事、暮らしや社会に影響するニュース

割合は目安です。重要なニュースや本当に面白い発見があれば、分野の比率より価値を優先します。ニュースが少ない日は無理に本数を増やしません。

## 放送の方針
- 日本語で、1回5〜8本を目安に紹介
- 原則として直近24〜48時間のニュースを中心に収集
- 公式発表・論文・開発元ブログなどの一次情報を優先して確認
- 重要な話題は複数の信頼できる情報源で照合
- 各ニュースに出典リンクを付け、事実と解説・感想を区別
- 重複・古い情報・出典不明の噂・宣伝だけの記事は避ける

## キャスター
- **レティシア** — 落ち着いた視点で背景や意味を整理する。
- **フィーユ** — 新しい発見や意外なポイントを親しみやすく紹介する。
- **シェロ** — ゲーム・技術・ガジェットに詳しく、仕組みや実用面を解説する。

詳しい選定基準は [NEWS_POLICY.md](NEWS_POLICY.md)、話し方は [CASTERS.md](CASTERS.md) を参照してください。

## 技術構成と公開
この局は [myradio テンプレート](https://github.com/monoradio102/myradio) を利用しています。プレーヤーは台本 JSON と音声ファイルを読み込んで番組を再生します。

- `station.json` — 局の設定
- `episodes.json` — 放送回の一覧
- `episodes/` — 放送台本
- `audio/` — 読み上げ音声（main ブランチには置かない）
- `NEWS_POLICY.md` — ニュース選定方針
- `CASTERS.md` — キャスター設定
- `AGENTS.md` — AIによる局の設定・運用手順

自動ニュース収集・台本作成・音声生成・GitHub Pages公開は、必要なAPIや実行環境を設定して動作確認した後に有効化します。現時点では未設定です。

## ライセンス・素材
プレーヤー等のプログラムは元テンプレートのライセンスに従います。テンプレート由来のキャラクター画像は仮素材として残しており、正式なキャスター画像・音声は今後、利用条件を確認したうえで設定します。
